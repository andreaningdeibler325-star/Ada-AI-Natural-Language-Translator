Ada NLT — Single microphone button

Replace index.html, style.css, app.js, voice-input.js in your project folder with the ZIP contents. Back up your existing files first.

Start Speaking begins browser speech recognition; button becomes red Stop Speaking. Recognized speech is shown in the text area as it arrives. Stop Speaking finishes recognition. Translate uses your existing Node backend on localhost:3001.

Auto Detect for speech uses the browser language, not universal spoken-language detection. Choose a source language for other speech languages. Browser speech recognition support varies; microphone permission and network may be needed.
